# Visualizar Progresso Geral  
**Ator:** Usuário  

**Descrição:** Permite ao usuário verificar seu progresso geral ao longo de determinado período de tempo   

**Fluxo Principal:**  
*1.* Usuário seleciona um intervalo de tempo  
*2.* Sistema coleta dados de hábitos no período  
*3.* Sistema calcula métricas de progresso (ex: hábitos concluídos, nível de satisfação)  
*4.* Sistema apresenta o progresso ao usuário  
*5.* Sistema permite ao usuário visualizar dados  

**Fluxos alternativos**  
*1a.* Intervalo de tempo inválido -> Sistema solicita correção  
*2a.* Nenhum dado encontrado no período -> Sistema informa ausência de dados
