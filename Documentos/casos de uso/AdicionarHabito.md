# Adicionar hábito à rotina  
**Ator:** Usuário  

**Descrição:** Permite ao usuário adicionar um hábito à sua rotina  

**Fluxo Principal:**  
*1.* Usuário visualiza lista de hábitos disponíveis  
*2.* Usuário seleciona um ou mais hábitos  
*3.* Usuário define configurações do hábito na rotina (frequência, horário, etc.)    
*4.* Sistema valida as configurações  
*5.* Sistema adiciona os hábitos à rotina do usuário  
*6.* Sistema confirma sucesso    

**Fluxos alternativos:**   
*1a.* hábito desejado não encontrado -> Usuário informa um novo hábito -> Sistema executa caso de uso *Criar hábito*  
*4a.* Configuração inválida -> Sistema informa erro e solicita correção
