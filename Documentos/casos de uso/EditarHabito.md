# Editar hábito
**Ator:** Usuário  

**Descrição:** Permite ao usuário alterar as configurações de um hábito de sua rotina   

**Fluxo Principal:**  
*1.* Usuário seleciona um hábito da sua rotina  
*2.* Usuário altera as configurações do hábito    
*3.* Sistema valida os dados informados    
*4.* Sistema atualiza o hábito   
*5.* Sistema informa sucesso   

**Fluxos alternativos:**  
*3a.* Dados inválidos (campo vazio ou formato incorreto) -> Sistema informa erro e solicita correção
