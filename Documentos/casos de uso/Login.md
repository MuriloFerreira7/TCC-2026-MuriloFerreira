# Login
**Ator:** Usuário  

**Descrição:** Permite ao usuário acessar o sistema por meio de credenciais válidas  

**Fluxo Principal:**   
*1.* Usuário informa dados(e-mail, nome de usuário, senha)  
*2.* Sistema valida formato dos dados  
*3.* Sistema autentica usuário   
*4.* Sistema informa sucesso  

**Fluxos alternativos:**  
*2a.* Dados inválidos (campo vazio ou formato incorreto) -> Sistema informa erro e solicita correção    
*3a.* Usuário não encontrado -> Sistema informa que a conta não existe e sugere cadastro
