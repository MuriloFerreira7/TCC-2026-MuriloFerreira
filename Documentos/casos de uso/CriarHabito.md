# Criar hábito
**Ator:** Usuário  

**Descrição:** Permite ao usuário cadastrar um hábito no sistema  

**Fluxo Principal:**  
*1.* Usuário define nome, tipo (contador, sim ou não), frequência, horários e notificações  
*2.* Sistema valida as especificações do hábito  
*3.* Sistema integra hábito a lista de hábitos  
*4.* Sistema informa sucesso   

**Fluxos alternativos:**  
*2a.* Dados inválidos (campo vazio ou formato incorreto) -> Sistema informa erro e solicita correção
