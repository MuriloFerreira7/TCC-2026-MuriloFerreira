# Marcar hábito como concluído   
**Ator:** Usuário  

**Descrição:** Permite ao usuário marcar um hábito de sua rotina como concluído  

**Fluxo Principal:**  
*1.* Usuário escolhe um dos hábitos da rotina   
*2.* Usuário marca hábito como concluído    
*3.* Sistema registra a conclusão do hábito  
*4.* Sistema informa sucesso    

**Fluxos alternativos:**    
*2a.* Hábito já marcado como concluído -> Sistema informa que o hábito já foi concluído
