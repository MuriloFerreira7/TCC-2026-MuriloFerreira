# Remover Habito da rotina  
**Ator:** Usuário  

**Descrição:** Permite ao usuário remover um hábito de sua rotina 

**Fluxo Principal:**  
*1.* Usuário escolhe um dos hábitos da rotina   
*2.* Sistema solicita confirmação ao usuário  
*3.* Sistema remove o hábito da rotina do usuário    
*4.* Sistema informa sucesso  

**Fluxos alternativos:**    
*2a.* Usuário não confirma remoção -> Sistema cancela a operação
