# Configurar Notificações  
**Ator:** Usuário  

**Descrição:** Permite ao usuário entrar em um grupo de gestão de hábitos   

**Fluxo Principal:**  
*1.* Usuário navega até a parte de grupos dentro do sistema  
*2.* Usuário digita código do grupo requerido  
*3.* Sistema intgra usuário ao grupo  
*4.* Sistema compartilha hábitos de usuários de acordo com as preferências do grupo  

**Fluxos alternativos:**  
*2.* código inválido -> Sistema informa erro e solicita correção
