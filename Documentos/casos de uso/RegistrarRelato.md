# Registrar relato por período  
**Ator:** Usuário  

**Descrição:** Permite ao usuário registrar um relato e um nível de satisfação associados a um período de tempo    

**Fluxo Principal:**  
*1.* Usuário define um período (data ou intervalo)  
*2.* Usuário escreve um relato sobre o período   
*3.* Usuário informa seu nível de satisfação  
*4.* Sistema valida os dados informados  
*5.* Sistema registra o relato associado ao período  
*6.* Sistema informa sucesso  

**Fluxos alternativos:**    
*1a.* Período inválido -> Sistema solicita correção  
*4a.* Dados inválidos -> Sistema solicita correção
