# Configurar Notificações  
**Ator:** Usuário  

**Descrição:** Permite ao usuário definir preferências de lembretes e notificações dos hábitos   

**Fluxo Principal:**  
*1.* Usuário acessa as configurações de notificações  
*2.* Usuário define as preferências desejadas (horários, frequência, etc)   
*3.* Sistema valida as configurações informadas  
*4.* Sistema atualiza as preferências de notificações  
*5.* Sistema informa sucesso  

**Fluxos alternativos:**  
*3a.* Dados inválidos (horário inválido  ou formato incorreto) -> Sistema informa erro e solicita correção
